# Jules Desktop Pet

Um pet de área de trabalho em **pixel art** para Windows inspirado no mascote polvo roxo do **Jules** (`jules.google`).

## Como rodar

- **Modo rápido (sem abrir janela de terminal):** dê um duplo clique em `start_jules.bat`.
- **Pelo terminal:**
  ```powershell
  uv run main.py
  ```

## Interações e Controles

- **Arrastar com o botão esquerdo:** pegue o Jules e solte-o com impulso pela tela.
- **Clique esquerdo:** ele dá um pulinho feliz com bochechas rosadas e estrelinhas pixeladas.
- **Duplo clique:** salto animado com explosão de corações e estrelas.
- **Passar o mouse fazendo carinho (movimento lateral):** solta coraçõezinhos.
- **Olhos dinâmicos:** o Jules acompanha sutilmente a posição do cursor e pisca naturalmente.
- **Clique direito (ou ícone na bandeja do Windows):** abre o menu para:
  - Ativar/desativar **Seguir o mouse**
  - Alternar **Modo de movimento** (*Flutuar livremente* ou *Andar na barra de tarefas*)
  - Mudar **Tamanho** (*Pequeno*, *Médio*, *Grande*)
  - **Sempre no topo**
  - **Dormir / Acordar**
  - **Centralizar na tela**
  - **Sair**
